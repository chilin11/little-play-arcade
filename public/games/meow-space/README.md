# 喵喵星际队

一个糖果太空风的 Q 版三轨射击小游戏。原生 HTML / CSS / JavaScript，无构建步骤、无运行依赖。

## 开始游戏

直接用现代浏览器打开 `index.html` 即可。

也可以在本目录运行：

```sh
python3 -m http.server 5173
```

然后访问 <http://localhost:5173>。

## 操作

- `←` / `→` 或 `A` / `D`：在三条跑道间左右移动，主角不能前后移动。
- 自动射击，无需按住射击键。
- `空格` 或点击「星星冲击」：能量满时清除小怪和敌方子弹，并伤害 Boss。
- `P` / `Esc`：暂停、继续。切换标签页或离开窗口时自动暂停。
- 手机：点击跑道、底部三轨按钮，或在游戏画面左右滑动。
- 右上角音符按钮：开关音效，默认静音。

## 内容

- 10 个主题关卡，第 3、6、9、10 关有 Boss。
- 3 种普通敌人，Boss 攻击前会标记危险跑道，始终保留安全跑道。
- 6 级武器，包含双弹、三弹、加速射击和彩虹弹。每次升级分别需要 2 / 3 / 4 / 5 / 6 颗糖果，通关火力礼包提供 2 颗糖果。
- 多发子弹共享一轮伤害预算，满级基础秒伤约为初始的 3.25 倍；额外伤害加成封顶 30%，射速加成封顶 20%。界面显示升级进度和理论秒伤（所有弹命中时）。
- 星星冲击对 Boss 单次伤害不超过其最大生命的 12%，满级糖果只加分、不再额外充能。
- 火力糖果、回血爱心、泡泡护盾、加分充能星星四种掉落。
- 每次通关回复生命、补充能量，并选择一项永久强化（本轮冒险内）。
- 初始 5 颗爱心，受伤后有短暂无敌。普通敌人漏过不会扣血。
- 失败可满血重试当前关卡，恢复入关时的分数和强化，不重复累积奖励。
- 最佳分数保存在当前浏览器本地；禁用本地存储时仍可正常游玩。

所有角色、特效和场景均由 Canvas / CSS 矢量绘制，不依赖远程图片。此聚合站副本已移除 Google 字体请求，使用系统字体；另增加了窄屏 iframe 的布局适配。Documents 中的原始游戏未修改。

## 文件

- `index.html`：页面布局和游戏界面。
- `style.css`：糖果色主题、响应式布局。
- `game.js`：关卡配置、战斗逻辑、角色绘制、音效和输入。

调整关卡可以修改 `game.js` 顶部的 `levels` 数组；生成节奏和敌人强度分别在 `spawnWave()`、`spawnEnemy()`，Boss 行为在 `update()`。
